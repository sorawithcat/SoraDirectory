# SoraDirectory 优化验收记录

## 交付结论

《优化规划》中的两条主线已作为一个完整目标实现，没有在里程碑边界提前结束。产品仍保持本地优先、无账号、无云同步、无多人协作的既有边界，也没有引入新框架或运行时依赖。

## 已交付能力

- 统一目录、锚点和方法引用：选择器支持搜索、当前目录、当前分支、最近和收藏范围，同时兼容原有手工引用格式。
- 方法模型与配置：集中注册触发器和动作，支持版本迁移、未知字段保留、自然语言摘要、内联校验、条件组、顺序/并行、失败策略、延迟、限时、防抖、节流和嵌套分支。
- 方法扩展：覆盖导航、内容、变量、状态、提示、确认、面板、组件、受控样式和动画；支持更多键盘、可见性、时间、媒体和指针触发器。
- 方法管理：可搜索、筛选、排序、定位、启停、复制、编辑、删除、查看流程与关系、套用/保存预设和升级旧配置；编辑器测试沙盒已移除。
- 编辑体验：新增全局命令搜索、目录过滤、上下文链接动作、工作区模式、问题中心、可访问状态反馈和移动端快捷操作。
- 保存与恢复：自动保存最新草稿，定期保留最多 20 个快照，可比较并整份或选择目录恢复；选择子目录时自动补齐必要祖先。
- 媒体管理：批量队列、取消和重试、拖放插入指示、资源筛选、属性编辑、全引用替换和孤立资源清理。
- 导出安全：预检目录、链接、锚点、媒体、方法目标和嵌套引用，区分阻断、风险与信息；外链仅接受安全协议，导出运行不调用浏览器原生弹窗。
- 内置说明：移除解谜游戏模板，补充方法、搜索、草稿、媒体、预检和移动端操作说明；新建文件默认创建并选中“默认目录”。
- 目录上下文：每个目录独立保存滚动和选区，重复点击当前目录不回顶，明确提供“回顶部”。
- 关系与结构化内容：反向链接、循环/孤立关系、目录标签/状态/日期/优先级/自定义字段、智能集合和可复用内容块。
- 扩展能力：方法流程视图、声明式扩展包权限检查、受控组件库和内容质量助手；继续禁止任意用户脚本、事件属性、远程资源和无约束 CSS。
- 本地版本：草稿按文档签名隔离，支持命名快照、文本变化片段、保留上限、容量提示、整份或选择目录恢复。
- 存储与诊断：容量趋势、媒体 SHA-256 去重、预计释放空间、缺失引用修复、重新扫描、迁移能力和脱敏诊断摘要。
- 知识库互操作：Markdown 文件夹、Front Matter、Obsidian 双链和 `_assets` 目录支持；冲突、非法文件名、缺失资源和循环在写入前预检，方法仅降级为说明文字。
- 发布与导出：发布预设/比较/回退，精简/标准/完整能力配置，目录收起、目录内大纲、阅读进度、单 HTML/静态目录/PWA 三种形态；外观固定为原有浅色样式，加密 PWA 会安全降级为静态目录。
- 2026-09-15 界面回调：修复发布设置和目录字段因 content-box 撑宽产生的横向滚动；移除导出主题选项，旧的深色/跟随系统配置会自动归一为浅色；删除强制居中的阅读模式和打印入口，桌面工具仅收起/展开目录，正文保持原有左对齐和边距。
- 颜色选择：文字颜色按白色正文背景评估自身对比度；只有背景颜色才推荐搭配黑色或白色文字。
- 链接着色：完整选中链接文字时，颜色会直接写入链接节点，不再被默认链接蓝色覆盖。
- 链接选择：范围下拉框获得焦点或切换范围时保持候选面板展开，不再被输入框失焦计时器误关闭。
- 受控组件库：修复错误依赖 `window.markdownPreview` 导致插入静默失败；缺项、无效锚点、跨目录和锚点顺序错误改为弹窗内提示，并补充实际用途与执行时机说明。
- 同类问题回归：可复用内容块改为读取实际编辑区并补齐空目录、循环和失效源提示；扩展包组件预设可在组件库选择，包内容必须匹配能力声明；确认框与 Toast 调整到功能弹窗之上；从方法配置打开关系或预设弹窗时，新弹窗提升到前层，后层配置暂停交互并在关闭后恢复。
- 上传更新：编辑器 HTML 声明不缓存；启动加载器、设计系统 CSS 和全部功能脚本在每次刷新时使用同一动态版本参数，避免新旧静态资源混用。
- 性能与持续回归：Worker 索引、指纹缓存、1000 目录约 10 MB 预算基准，以及无依赖 CDP 桌面/移动浏览器端到端测试。

## 证据边界

- 验收在本机 Chromium 环境完成；没有将单一浏览器结果扩大为所有浏览器兼容性结论。
- 未执行部署、发布、提交或推送；本项目为本地静态应用，本轮也未新增运行时依赖。
- 自动化检查用于防回归，真实导出网页的运行结果单独完成浏览器验收，没有以静态检查代替运行验收。
- 尚未将 Chromium/Edge 结论扩大为 Firefox/WebKit；未宣称真实 PWA 安装、外部静态托管、64 MB 以上视频和全部加密组合已完成外部环境验收。
