# 格式功能实施记录

对应《格式功能审查与扩展建议-2026-09-22.md》的 F1–F11、N1–N7。本文件记录本地源码实施；按用户要求，未运行测试、语法检查、构建、浏览器或真实输入法验收，不能据此宣称运行效果已验收。

## 已实施

| 范围 | 源码行为 |
| --- | --- |
| F1 选区边界 | 格式命令只接受当前正文的有效 Range；绑定文档/目录、DOM 重建代次和内容；弹窗返回后重新核对。正文快捷键只在正文处理，帮助弹窗不响应正文格式快捷键。 |
| F2 局部格式 | 按实际文本节点与 Range 偏移拆分，不按相同文字查找；保留未选中部分和其他嵌套节点；混合选区统一应用，全部已应用时取消。 |
| F3 列表 | 用节点转换保留链接和文字格式；支持三种列表互换、取消、缩进、减少缩进、空项回车退出，不再把普通文字拼成 HTML。 |
| F4 块格式 | 正文/标题改为块级类型选择；段落和引用操作独立处理；不把整个跨块 HTML 塞入标题或 p 标签。 |
| F5 表格 | 行、列、表头合并为一张表单，取消结束操作；最多 100 行、20 列且总单元格不超过 1000；增加增删行列、首行表头、单元格对齐和删除整表。含合并单元格的旧表格保留内容，行列调整会提示限制。 |
| F6 输入 | 支持光标位置启用文字格式；移除每次输入后强制跳出格式的逻辑；输入法组合过程中暂停格式重写，结束后统一记录。 |
| F7 撤销 | 正文格式与输入接入独立事务/历史，支持 Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z；链接、锚点、方法和代码块再编辑也接入；正文历史引用的媒体加入删除保护。 |
| F8 颜色 | 按精确 CSS 属性读取和修改前景/背景色；显示混合颜色提示，保留现有调色板与对比度提示，增加恢复默认色入口。 |
| F9 代码 | 纯文本不高亮；高亮改为对原始代码分词后逐段转义，不对已生成的标签继续替换；持久化去除显示用高亮与复制按钮，编辑器/网页导出时重新生成显示。 |
| F10 Markdown | 增加任务状态、嵌套列表、代码语言和可变长度代码围栏、简单表格及受控 HTML 内容导入；导出提供丰富 HTML / 通用 Markdown 选择，预检列出降级提示，复杂表格保留 HTML。 |
| F11 格式入口 | 顶部、悬浮栏、更多格式、手机命令和全局搜索读取共同格式定义；正文/标题使用选择器，显示已应用及混合状态；说明中的命令清单也从定义生成。 |
| N1–N2 常用排版 | 清除文字样式、恢复正文、对齐、行距、段前段后间距；不改变整个导出页面的默认排版。 |
| N3–N4 内容块 | 提示/注意/警告/成功块；直接插入与编辑折叠标题、正文和导出初始展开状态。原有方法组件入口继续保留。 |
| N5 注释 | 当前目录内脚注/尾注，自动编号、返回引用、编辑/删除；处理重复粘贴的引用 ID，缺失注释显示明确文字并保留目标用于问题检查。 |
| N6 语义格式 | 键盘按键、术语/解释成对内容。 |
| N7 格式刷 | 复制/应用允许的文字与段落样式，不复制链接目标、锚点 ID、方法配置或组件状态。 |

## 文件与兼容性

- 新增 `js/editorFormatting.js` 管理正文事务和格式定义；原 `applyFormat` 保留为转发入口。没有新增第三方依赖。
- 新增 `js/contentFormats.js` 提供正文内容块的共享样式、注释整理与存储清理；编辑器和导出网页使用同一份样式。
- 更新 `index.html` 脚本清单；删除运行时已由统一定义生成的旧格式按钮清单。
- `.sora` 继续保存 HTML 内容，没有改变包版本或数据库结构；新内容块使用普通 HTML 和限定的 data 属性。
- 正文撤销只在当前会话保留，每目录最多 60 条，按约 8 MB 的历史预算裁剪；单条大内容仍可能超过预算。文档加载/结构重建会使旧正文历史失效，持久恢复继续依赖草稿和快照。
- Markdown 不是所有网页交互的无损替代；方法逻辑仍不导出为 Markdown。丰富格式依赖接收端对 HTML 的支持，通用模式会简化样式，写入前有提示。
- 数学公式、流程图、拼音注音、复杂多栏、合并/拆分表格单元格以及任意字号没有纳入本轮，沿用审查中的暂缓范围。

## 内容块嵌套与勾选项修正

- 原折叠块、提示块命令通过祖先查找自动进入编辑模式，因此无法在同类块内继续新建。现在“插入提示块 / 插入折叠块”始终新建；“编辑当前提示块 / 编辑当前折叠块”是独立命令，修改最近的对应块及其直属标题。
- 两类块支持同类嵌套与相互嵌套，并可放入单元格、列表项、引用、术语解释正文。当前正文区域内的行内内容会先组成段落，再插入或包裹，避免把块插入文字标签或移动外层容器。
- 光标状态下在当前插入点新建空块，并进入子块正文；选区状态下包裹同一区域的正文段落和完整块。子块后复用或补充普通段落，供父级继续输入。
- 新增“插入引用块（可嵌套）”；原“引用”继续负责当前段落的引用切换。表格、代码块、分隔线、术语解释也使用同一套正文区域定位。列表状态和缩进以当前内容区域为边界，不因外层列表而误改父级。
- 嵌套表格的合并单元格判断和单元格对齐只检查当前表格；取消列表时，折叠、提示等块继续作为块保留，不塞进普通段落。
- 块标题和只读内容不是块插入区域；跨不同单元格或内容块层级的选区需先缩小范围。
- 格式表单中的勾选项改为方框在左、文字在右的同行布局；统一 18px 方框、44px 行点击区域，点击标签文字也能切换。覆盖表格首行表头、折叠默认展开、删除脚注等共用表单。
