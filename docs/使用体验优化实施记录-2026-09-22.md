# 使用体验优化实施记录

本轮对应《使用体验优化审查-2026-09-22.md》的 U1–U8。以下为本地源码实施状态；按用户要求，未运行测试、语法检查、构建、性能基准或浏览器验收。

| 项目 | 已落实的源码行为 |
| --- | --- |
| U1 媒体保护 | 新建保留共享媒体；删除与批量清理检查当前文档、已登记文档、草稿、历史快照和撤销记录；文件或媒体写入期间暂停清理；媒体库展示保留原因及可释放空间。 |
| U2 保存一致性 | 普通保存经过统一入口，同一时间只处理一个保存/导出任务；固定正文、元数据、颜色与编辑版本；先等待媒体导入，缺失资源不能静默跳过；保存期间的新编辑保留未保存标记及草稿；下载回退仅提示已发起下载。 |
| U3 草稿恢复 | 新建、加载及 Markdown 导入前保护当前草稿；重新加载文件不会直接删除最新草稿；较新草稿可选择恢复或暂不恢复；草稿面板增加各文档最新草稿入口与独立删除动作；恢复前保存当前状态。 |
| U4 保存/导出入口 | Ctrl+S 直接沿用当前文件及保护方式，取消重复快捷键处理；导出面板集中提供 .sora、网页、增量、差异、范围、密码和媒体存放选项，展示目录数及兼容性说明；密码不写入持久设置。 |
| U5 独立帮助 | 点击说明时可选择“弹窗查看”或“插入当前作品”，默认弹窗查看；弹窗内支持搜索和章节跳转，不修改作品，也保留插入入口；插入前确认，插入后可撤销并参与保存和导出；首次空工作区创建默认目录。 |
| U6 手机操作 | 手机快捷栏、更多菜单和命令搜索共用命令定义；快捷按钮同步禁用和保存状态；更多菜单可搜索、显示分组与最近使用，并包含扩展命令。 |
| U7 问题定位 | 目录问题携带稳定目录 ID，能确定位置时记录锚点、媒体或元素索引；不再按目录名包含关系猜测；点击后定位并短暂标记，标记不进入正文保存。 |
| U8 后台检查 | 监听正文/结构与媒体变化事件，停止对所有输入框触发全量检查；缓存目录解析、本地检查、链接和方法结果；依赖图变化时失效，导出前强制完整检查；草稿按文档索引读取，快照指纹与整理只在快照周期执行。 |

## 文件与数据影响

- 新增 `js/saveWorkflow.js`，已加入 `index.html` 启动清单；没有新增第三方依赖。
- 草稿数据库由版本 1 升至版本 2，保留原 `drafts` 数据，新增 `documentId` 索引与文档媒体引用记录。旧页面阻碍升级时明确提示保存并刷新旧页面，然后重试。
- `.sora` 文件仍使用现有 V1 包格式，密码不进入导出偏好或文档身份记录。
- 其他文档和历史版本仍需要的媒体继续保留，因此清理空间以当前可安全删除的实际资源为准。
- 已同步内置使用说明中的新建、保存、导出、草稿与媒体清理说明。

完成了源码阅读、调用关系和差异检查；没有执行任何运行验证或部署。代码提交与推送不代表完成实际场景验收。

后续获准测试后，优先验证跨文档媒体恢复、保存期间继续编辑、媒体导入失败、下载取消、数据库升级、加密保存，以及手机导出面板与问题定位。原审查中暂缓的大视频流式解密专项未包含在这 8 项实现中。

## 媒体、草稿加载与多项目补充修复

用户报告两个窗口曾持续加载，随后确认同时开着两个编辑器页面。源码确认旧版草稿连接没有释放升级占用，新版 `onblocked` 只更新状态而不结束读取；媒体列表又先等待草稿写入和引用扫描。只读查看现有页面时，草稿列表已显示，因此未捕捉到实际阻塞事件，也未对修复进行运行验证。

- 草稿和媒体共用数据库连接管理：受阻立即返回明确原因，打开超时在 15 秒后提示；重试共用未结束请求，迟到连接释放，正常连接在版本切换时释放。
- 草稿读取失败不再伪装成空快照；窗口提供重试。最新草稿与当前文档快照并行读取，快照按主键前缀读取，避免同时取回最新草稿正文。
- 媒体列表不再等待草稿引用扫描；检查完成前保持不可清理，失败时可重试，查看与插入仍可使用。实际删除仍重新检查引用。
- 当前项目身份由 `localStorage` 改为标签页独立的 `sessionStorage`。刷新同一页保留身份；独立新开页面创建新项目，不自动跟随另一页的项目。原有草稿不删除，可从跨文档草稿列表恢复；同一文档的同时编辑没有实时合并机制。
- 新增 `js/storageDatabase.js` 并加入启动顺序；未新增依赖、提高数据库版本或修改文件格式。内置说明已同步。

仅完成静态源码核对，未运行测试、语法检查、构建或修复后的浏览器验收，未部署。
