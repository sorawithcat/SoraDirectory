# SoraDirectory 优化规划

> 状态：规划范围已于 2026-09-14 全量实现。本文件保留需求边界与验收口径；实际交付证据见[优化验收记录](优化验收记录.md)。下列里程碑仅用于能力分组，不作为阶段性停止点。

## 1. 目标与范围

SoraDirectory 原有目录树、富文本编辑、搜索替换、锚点和内部链接、方法配置、媒体管理、草稿恢复、多格式导入导出、加密保存以及导出预检等能力。本轮优化同时推进两条主线：

1. 盘活已有能力：降低查找、输入、配置、验证和恢复成本，让已有功能真正可发现、可组合、可确认。
2. 扩展新能力：在统一方法模型和运行机制的基础上，增加导航、状态、条件、流程和交互组件。

产品定位保持为本地优先的目录内容编辑器和交互式网页生成工具。本阶段不引入账号、云同步、多人协作或公共 SaaS 体系。

## 2. 当前问题判断

### 2.1 功能问题

- 锚点、目录和链接目标主要依赖手工输入，容易输错，也无法充分利用现有搜索能力。
- 方法配置以字段表单为中心，用户难以快速理解“何时、对谁、做什么”。
- 方法是否命中目标、范围是否正确，通常要到导出网页后才能确认。
- 当前导出预检能够发现目录、链接、锚点和媒体问题，但方法引用还没有形成同等级的检查和定位能力。
- 搜索、最近目录、收藏目录、面包屑、内部链接和方法目标选择各自独立，缺少统一导航入口。
- 自动草稿、撤销记录和显式保存之间缺少清晰的状态说明及可选择的恢复历史。
- 功能持续增加后，顶部工具栏承载过多低频按钮，新功能继续加入会进一步降低可发现性。

### 2.2 样式与交互问题

- 方法弹窗采用纵向长表单，字段层级和依赖关系不够直观。
- 桌面端主要依赖横向工具栏，窗口变窄时只能换行或横向滚动，缺少上下文工具。
- 错误反馈多以 Toast 呈现，无法稳定关联到具体字段和目标。
- 弹窗、搜索结果、目录导航和媒体管理尚未形成统一的选择、空状态、错误状态和键盘操作规范。
- 目录颜色允许自由设置，但缺少可读性提示和统一色板。

### 2.3 技术约束

- 编辑器仍采用经典全局 JavaScript 模块，目录内容使用数组数据结构和 DOM 状态共同维护，不适合在本阶段整体改写框架。
- 方法配置位于编辑端，方法执行逻辑主要嵌入导出网页生成代码。继续直接增加分支会扩大两端行为漂移风险。
- `.sora`、JSON 和已导出网页属于现有数据契约，新增方法必须支持版本识别、旧配置读取和安全降级。

因此，最小安全路线是先建立共享的“引用选择”和“方法定义”基础，再扩展新方法；不进行无关框架迁移。

## 3. 主线一：充分利用已有功能和样式

### A1. 统一目录与锚点选择器（P0）

建立一个可复用的引用选择器，替换方法、内部链接和替换来源中的纯手工输入体验。

功能范围：

- 输入时搜索目录名、目录 ID、锚点名和锚点附近正文。
- 按目录路径分组展示锚点，避免同名目录或同名锚点混淆。
- 支持当前目录、全部目录、最近使用和收藏目录四种范围。
- 选择前锚点后，后锚点默认仅显示同目录且位置在后的锚点。
- 选择结果展示目标是否存在、目录路径和内容摘要。
- 支持直接选择整个目录，也支持选择目录内的锚点范围。
- 保留手工输入模式，兼容 `#锚点`、`dir:目录ID#锚点` 和 `name:目录名#锚点` 等旧写法。
- 统一供“插入链接、编辑链接、方法目标、方法替换来源、跳转目录”使用。

验收标准：

- 普通操作不需要复制目录 ID 或记忆锚点格式。
- 不存在的目录或锚点在确认前即可被识别。
- 前后锚点不在同一目录时，错误直接显示在字段附近。
- 旧文件中的手工引用可正常回显和再次编辑。

### A2. 方法配置器重构（P0）

将方法配置从“字段堆叠”改为可视化语句：

> 当【触发方式】作用于【触发对象】时，对【目标范围】执行【动作】，执行范围为【一次/每次】。

交互调整：

- 将触发、目标、动作和执行规则分为四个明确步骤，但允许在同一弹窗内完成。
- 根据动作类型渐进显示必要参数，不展示无关字段。
- 在弹窗顶部实时生成自然语言摘要。
- 展示目标内容摘要、预计影响的目录和范围。
- 错误固定显示在对应字段下，不使用短暂 Toast 代替表单校验。
- 嵌套方法改为可排序步骤列表，支持复制、禁用、删除和展开编辑。
- 增加“测试当前方法”和“一键还原测试结果”。
- 明确标记“只会在导出网页运行”的行为，避免误认为编辑器内已经生效。

验收标准：

- 用户在确认前能看懂完整方法语义。
- 目标缺失、范围错误、循环嵌套和不支持组合均能提前发现。
- 编辑已有方法时不丢失未知字段，保障向前兼容。

### A3. 搜索能力复用与全局命令入口（P0）

- 在现有搜索替换基础上抽取统一搜索索引，供目录、锚点、方法和媒体选择复用。
- 增加全局命令搜索，建议快捷键为 `Ctrl+K`。
- 命令搜索覆盖目录跳转、锚点跳转、工具栏命令、最近目录、收藏目录和常用导出动作。
- 搜索结果提供上下文动作，例如“打开目录”“插入此目录链接”“以此锚点配置方法”。
- 目录侧栏增加即时过滤、仅显示当前分支和展开所有匹配路径。

验收标准：

- 不依赖顶部按钮也能找到全部主要功能。
- 键盘可以完成搜索、选择和执行。
- 搜索索引在目录改名、移动、删除和正文更新后能够正确刷新。

### A4. 预检前置与问题定位（P1）

- 将导出预检从单次报告扩展为编辑期检查。
- 目录树显示断链、重复锚点、方法目标失效和媒体缺失徽标。
- 点击问题直接跳转到对应目录和内容位置。
- 新增方法检查：目标引用、来源引用、无效动作参数、重复方法 ID、循环或超限级联。
- 导出前仍保留完整报告，但按阻断错误、风险警告、信息提示分级。
- 对可以自动修复的问题提供明确操作，不静默修改内容。

### A5. 保存、草稿和恢复体验（P1）

- 统一显示“未保存、已保存、草稿已更新、媒体仍在写入、保存失败”等状态。
- 草稿从单一最新版本扩展为有限数量的时间点快照。
- 恢复前展示文件名、更新时间、目录数量和差异摘要。
- 支持仅恢复某个目录，而不是只能整体覆盖。
- 明确区分撤销、自动草稿、文件保存和另存为的职责。

### A6. 媒体工作流优化（P1）

- 批量插入时展示队列、单项进度、失败原因、取消和重试。
- 拖放时显示最终插入位置，避免媒体落在错误段落。
- 统一图片和视频属性面板，管理说明文字、尺寸、对齐和加载策略。
- 媒体管理器支持按当前目录、未引用、类型和体积过滤。
- 删除媒体前展示引用目录；替换媒体时保留原引用关系。

### A7. 工具栏与工作区样式优化（P1）

第一阶段采用低风险的信息架构调整，不立即重做整个界面：

- 顶部保留新建、保存、撤销、搜索和预览等全局高频操作。
- 格式工具只在正文编辑状态出现。
- 目录操作在目录选中或右键时出现。
- 自动化相关功能集中到“方法”入口。
- 桌面端和移动端共用可固定快捷操作机制。
- 低频操作进入“更多”菜单和全局命令搜索。
- 统一按钮高度、图标语义、危险操作颜色、焦点状态和禁用状态。
- 目录颜色使用预设色板并检测文字对比度，同时保留自定义颜色入口。

第二阶段再评估将界面分为“写作、整理、自动化、预览”四种工作模式，避免首次改造范围过大。

## 4. 主线二：功能和样式扩展

### B0. 方法定义基础（P0，新增方法前置条件）

建立统一的方法注册结构，每个触发器和动作声明以下内容：

- 唯一类型、显示名称和配置版本。
- 可用目标类型：目录、单锚点、锚点范围或当前元素。
- 配置字段及默认值。
- 校验规则和自然语言摘要生成方式。
- 编辑器测试执行器。
- 导出网页执行器或可序列化运行定义。
- 旧版本迁移和未知类型降级策略。

编辑端和导出端应以同一份定义为来源，避免分别维护多个大段条件判断。现有七类方法先迁移到注册结构，行为保持不变，再增加新能力。

### B1. 导航类方法（P1）

- 跳转到目录或锚点。
- 返回上一浏览位置。
- 跳转到上一个或下一个同级目录。
- 展开指定目录后跳转。
- 跳转后短暂高亮目标。
- 按目录顺序进入下一步内容。

### B2. 内容类方法（P1）

- 在目标范围前追加、后追加或指定位置插入内容。
- 清空或删除锚点范围。
- 复制、移动或交换两个锚点范围。
- 引用其他目录内容，在来源更新后重新导出即可同步。
- 使用目录名、当前日期和变量生成模板内容。

破坏性内容动作在编辑器测试时必须使用临时副本，不能直接污染原文。

### B3. 状态、变量和条件（P1）

- 设置、增加、减少和切换变量。
- 支持布尔值、数字和文本三种基础类型。
- 状态作用域分为当前页面、当前会话和本地持久化。
- 根据变量、执行次数、元素可见性、复选框状态或当前目录决定是否执行。
- 支持 AND、OR 和否则分支，但第一版不引入任意脚本表达式。
- 提供计数器、进度和完成状态展示。

### B4. 触发与流程控制（P2）

新增触发方式：

- 双击、长按、键盘快捷键。
- 元素进入可视区域。
- 复选框或输入值发生变化。
- 音视频播放结束。
- 延时和定时触发。
- 离开目录或切换目录前后。

新增流程能力：

- 顺序执行、并行执行和延迟执行。
- 防抖和节流。
- 等待用户操作后继续。
- 失败后停止、跳过或执行备用动作。
- 明确最大执行次数，防止级联循环。

### B5. 交互与样式方法（P2）

- 自定义 Toast、确认框、弹层、抽屉和侧栏，不使用浏览器原生弹窗。
- 折叠区、标签页、步骤内容、进度条、单选、多选和文本输入组件。
- 添加、移除和切换受控样式类。
- 提供淡入、展开、滑入和强调等动画预设。
- 样式值优先使用主题变量和受控令牌，不开放任意 JavaScript 或无约束 CSS。
- 所有动画遵循减少动态效果设置，并提供无动画状态。

### B6. 方法复用与调试（P2）

- 将方法或方法组保存为个人预设。
- 预设参数化，例如使用时再选择目标目录、锚点和显示文本。
- 提供折叠内容、分步阅读、条件显示、目录导航等通用组合预设。
- 支持方法禁用、复制、排序和分组。
- 在导出预览中提供执行日志、当前变量、触发历史和运行状态重置。
- 提供方法关系视图，显示触发对象、目标和可能的级联路径。
- 不恢复解谜游戏模板；通用能力通过可组合预设表达。

## 5. 完整实施清单

以下里程碑用于组织依赖和验收，不代表分阶段交付；本轮目标要求全部完成后才结束。

### 里程碑 M0：统一基础

交付范围：

- 引用数据索引和统一目录/锚点选择器。
- 方法注册结构、配置版本和旧配置迁移。
- 将现有方法迁入注册结构，保持导出行为不变。
- 增加方法目标预检和基础回归样例。

完成条件：

- 旧 `.sora`、JSON 和页面内容能够读取、编辑、保存及导出。
- 编辑器摘要、校验和导出运行使用同一方法定义。
- 当前所有方法的触发与执行结果无行为回退。

### 里程碑 M1：盘活现有能力

交付范围：

- 可视化方法配置器和方法测试。
- 内部链接、替换来源接入统一选择器。
- 全局命令搜索和目录树过滤。
- 工具栏分层、编辑期问题徽标和保存状态统一。
- 媒体队列与属性面板的第一版。

完成条件：

- 创建常用方法不需要手工查目录 ID。
- 方法可在导出前完成目标检查和真实运行预览。
- 主要功能可通过工具栏、右键菜单或命令搜索中的一种稳定找到。
- 桌面窄窗口和移动端不出现关键操作不可达。

### 里程碑 M2：核心扩展

交付范围：

- 导航类、内容类方法。
- 基础变量、条件和状态持久化。
- 顺序步骤和延迟执行。
- 方法执行日志与状态重置。

完成条件：

- 可以无脚本完成“触发—条件—动作—跳转”的基础交互流程。
- 条件失败、目标缺失和执行超限都有可理解的结果。
- 新增配置在旧版无法执行时安全忽略并给出提示，不破坏正文。

### 里程碑 M3：高级交互

交付范围：

- 更多事件触发、并行及等待流程。
- 交互组件、受控样式和动画预设。
- 参数化预设和方法关系视图。
- 工作区模式与主题体系评估及实施。

完成条件：

- 复杂流程仍能在可视化界面中理解、测试和回退。
- 移动端、键盘操作和减少动态效果模式可用。
- 预设不会引入项目特定内容或重新加入已移除模板。

## 6. 全量交付策略

实现仍遵循“统一引用与方法定义 → 盘活现有体验 → 增加核心方法 → 扩展高级交互”的依赖顺序，但不中途结束。统一选择器、方法注册与迁移、配置弹窗、预检、方法扩展、管理调试、媒体、草稿、响应式和帮助说明均属于同一完整交付目标。

## 7. 验证与兼容要求

每个里程碑至少完成以下验证：

- 运行现有 JavaScript 静态检查。
- 使用旧 `.sora`、JSON 和包含嵌套方法的样例进行加载与重新保存。
- 验证当前目录、跨目录、同名目录、同名锚点、锚点缺失和锚点删除后的表现。
- 对每种现有触发器和方法类型验证编辑器测试与实际导出网页结果一致。
- 验证方法级联达到上限时可以停止并显示原因。
- 验证撤销、草稿恢复、文件保存和重新加载后配置不丢失。
- 验证桌面宽屏、窄窗口和移动端的键盘或触控可达性。
- 不以静态检查或编辑器模拟代替实际导出网页验收。

## 8. 当前不建议实施

- 在现有条件分支中直接连续追加大量方法类型。
- 为界面优化整体迁移到新的前端框架。
- 开放用户输入任意 JavaScript、HTML 事件或无约束 CSS。
- 在方法运行中使用浏览器原生 `alert`、`prompt` 或 `confirm`。
- 在本地编辑能力稳定前引入账号、云同步和多人协作。
- 未建立版本迁移前改变现有方法字段含义或 `.sora` 数据格式。

## 9. 决策结论

本轮目标是让目录、锚点和方法从“需要记住格式并在导出后试错”，转变为“可以搜索选择、即时校验、真实预览和安全扩展”。该目标已按完整范围交付，具体行为和证据边界以验收记录为准。
