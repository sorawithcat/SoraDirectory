# 服务器部署压缩包

入口：另存为 → 服务器部署压缩包（.zip）。生成的是文档阅读站点，不是在线编辑器。无新增第三方依赖，也不要求导出浏览器支持目录选择器。

原有单 HTML 导出保留，并在格式列表中独立显示为“单 HTML（.html，包含媒体）”。可选择全部目录、当前分支或手选目录，支持密码加密；选择该格式始终将媒体嵌入 HTML，不受之前的网站目录或部署包设置影响。

## 两种服务器模式

| 模式 | 导出范围 | 服务器要求 | 更新行为 |
| --- | --- | --- | --- |
| 通用静态包 | 全部目录 | 普通静态 Web 服务 | 完整覆盖更新，包含旧内容和新增内容；支持网页密码加密 |
| PHP 追加包 | 全部、当前分支或手选目录 | PHP 7.4+，目录只需可读 | 只带所选目录和媒体，新 ID 新增、同 ID 更新，未选旧目录保留；暂不支持密码加密 |

ZIP 根目录直接包含 `index.html`，不额外套一层文档目录。所有站内资源使用相对路径，支持网站根目录和子目录。每个追加包包含读取程序和通用资源，因此空站点也可部署；已有同格式站点无需修改目录清单或安装依赖。

## PHP 追加工作流

1. 在同一份源文档中新建或修改目录，选择 PHP 追加包并只勾选本次发布的目录。
2. 保存 ZIP，上传到原网站目录并解压覆盖同名文件；保留未覆盖的 `content/`、`media/`、`assets/` 文件。
3. 访问 `index.html`。`catalog.php` 只读扫描各目录 JSON，按文档身份汇总；无需数据库、Composer、上传接口或在线管理后台。
4. 每个目录的发布文件名由文档 ID 和目录 ID 决定。父目录已部署时恢复原层级；父目录不存在时先作为顶层显示，之后部署父目录会自动接回。

独立文档应使用独立网站子目录。同名目录不等于同一目录；应继续使用原 `.sora` 文档，避免重新创建文档身份。包只新增和覆盖，不自动删除已发布目录，也不会清理旧媒体。

旧版单 HTML、静态包或 PWA 中没有独立目录 JSON，首次切换为 PHP 追加模式必须先导出全部旧目录进行迁移。PWA 旧缓存需停用或改用新的部署子目录；包内 `DEPLOY.txt` 会说明。不能把“只选新目录”的包直接视为任意旧 HTML 的无损迁移工具。

## 文件组织与实现

- `assets/reader-*.js`、`assets/reader-*.css`：共用运行代码和样式，按内容生成稳定文件名；文档设置与运行代码分离。
- `content/*.json`：PHP 模式每个目录一个文件，包含正文、父目录、位置、媒体引用；目录元信息从完整源文档捕获，避免部分导出把父目录关系永久改为顶层。
- `content/*.js`：未加密静态模式的独立正文文件。
- `media/*`：未加密媒体按实际文件内容命名与去重；媒体引用也按内容生成稳定 ID，避免追加后新旧目录引用覆盖。
- `site.json`、`catalog.php`：仅 PHP 模式提供。每次访问不缓存目录响应；PHP 不接受客户端文件路径参数，不写文件。
- `DEPLOY.txt`：包内提供首次部署、追加、迁移、备份与回滚说明。用户原有的远程图片、图标、链接和外部服务不强制下载，仍依赖原地址。
- 加密静态包沿用既有 HTML/媒体加密，不把正文拆成明文文件；ZIP 本身不是密码压缩包。

ZIP 写入按 [PKWARE APPNOTE](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT) 组织文件头、CRC32、中央目录与 ZIP64 扩展。小型文本在浏览器支持时使用 [Compression Streams 的 raw DEFLATE](https://compression.spec.whatwg.org/)，媒体直接封装以避免重复压缩。优先使用浏览器私有文件系统暂存，下载后按已有下载流程延迟清理输出文件。

## 验证边界

仅完成源码与调用关系的静态核对。按用户要求，未运行测试、语法检查、构建、ZIP 解压验证、PHP 执行或真实服务器部署验收；不能据此宣称已经部署或通过多次追加实测。
